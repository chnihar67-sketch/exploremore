# 🌍 LOCALORA – Discover Beyond Destinations

### An AI-Powered Smart Local Tourism Business Portal

**LOCALORA** is a smart digital tourism platform designed to connect travellers with local tourism businesses, hidden destinations, homestays, tour guides, cultural experiences, and traditional businesses.

Our mission is to promote unexplored tourist destinations, support small local businesses, empower rural communities, and make local tourism more accessible through a single digital platform.

---

## 🚀 Project Overview

Many small tourism businesses struggle to gain online visibility, while travellers often find it difficult to discover authentic local experiences and lesser-known destinations.

LOCALORA addresses this gap by providing a centralized marketplace where tourists can discover destinations, explore local experiences, compare services, and submit booking requests.

The platform also integrates AI-powered travel recommendations to help users plan personalized journeys based on their interests, budget, and available time.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/LOCALORA.git
```

### 2. Navigate to the Project

```bash
cd LOCALORA
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the root directory.

Add your Firebase and Gemini API configuration.

```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```

Configure your Gemini API key using a secure backend environment variable. Do not expose secret API keys in frontend code.

### 5. Start the Development Server

```bash
npm run dev
```

Open the local development URL displayed in your terminal.
